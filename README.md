### Project Overview
Personal brand website for a professional drummer based in Accra, Ghana. Built to convert visitors into paying clients and showcase technical skills in Web Audio API.

1. **TRY MY KIT — Interactive Drum Machine**
   - Instruments: Kick, Snare, Hi-Hat, Tom, Ride, Crash, Clap, Cowbell, Rimshot
   - Keyboard mapping: Q W E A S D Z X C
   - Tech: Web Audio API, DOM Events, Audio Context Management

2. **WORSHIP PAD — Chord Synthesizer**
   - 12 Keys: C to B + Major/Minor, Warm/Bright, Strings/Airy Choir modes

   - Tech: State Management, Oscillator Nodes
